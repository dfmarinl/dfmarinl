## 🚀 Featured Projects

### 1. ChibchaWEB — Web Hosting Management Platform
A web hosting management platform designed around customer, employee, and administrator workflows. The project focuses on software architecture, domain modeling, and a modular application structure.

**Stack:** React · React Router · Tailwind CSS · Java · Spring Boot

- Designed the software architecture and UML models.
- Applied GoF design patterns to improve modularity and maintainability.
- Implemented the initial frontend structure and role-based navigation.
- Backend development in progress.

🌐 [Live Demo](https://chibcha-web.vercel.app/) · 💻 [Source Code](https://github.com/dfmarinl/ChibchaWeb)

### 2. PetMatch — Pet Adoption Management Platform
A web application developed collaboratively to support the pet adoption process, including application reviews and post-adoption tracking.

**Stack:** JavaScript · Express · MySQL · Tailwind CSS · Sockets · Jest

- Developed the adoption workflow and post-adoption tracking features.
- Implemented real-time updates using sockets.
- Contributed unit and integration tests for critical modules.
- Collaborated on requirements and task management using Jira.

🌐 [Live Demo](https://pet-match2-0.vercel.app/) · 💻 [Source Code](https://github.com/dfmarinl/PetMatch2.0)

### 3. IntegraServicios — University Resource Management
A web application for managing university resources, service units, reservations, loans, returns, and resource ratings.

**Stack:** JavaScript · Express · MySQL · Tailwind CSS · Jest

- Implemented user authentication using JWT.
- Developed resource management and loan workflows.
- Added availability validation to prevent reservation conflicts.
- Built resource ratings, statistics, and reporting functionality.

🌐 [Live Demo](https://integra-servicios.vercel.app/) · 💻 [Source Code](https://github.com/dfmarinl/IntegraServicios)

### 4. LaMilagrosaApp — Full-Stack Management App
A web application combining a Spring Boot backend with a React frontend, built to practice layered architecture and full-stack integration.

**Stack:** Java · Spring Boot · React

- Designed a REST API with Spring Boot following a layered architecture.
- Consumed the API from a React frontend with reusable components.
- Structured the project for maintainability and future feature growth.

💻 [Explore my repositories](https://github.com/dfmarinl?tab=repositories)
